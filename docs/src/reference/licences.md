# Licences

archiveview is Apache-2.0.

The release binaries include third-party crates, among them bobview's `pv`
crate and the [epics-rs](https://github.com/epics-rs/epics-rs) CA and PVA
libraries (EPICS-style open licence), and embed the Liberation Sans fonts
and a symbol subset of Noto Sans Math (both SIL Open Font Licence) and
egui's default fonts. Their notices are in `THIRD_PARTY_LICENSES.txt` in
each release tarball, generated by `scripts/third-party-licenses.py`.
