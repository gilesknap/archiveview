Module history

Expand description

Recent searches: the search box’s terms that were useful, newest first.

A term is remembered when a PV is added from its results (or the typed text itself is added), so typos and half-typed prefixes are not. The list is plain data: crate::Plot keeps one in memory, and the standalone app loads and saves it as history.json (see config::load_history). A host embedding the plot may persist it the same way, or not at all.
