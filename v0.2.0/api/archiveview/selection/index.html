Module selection 

Source
Expand description

The primary selection and the clipboard, for middle-click and the search box (see plot/paste.rs). Only the app reads them: the embeddable Plot has no clipboard dependency.

On X11 (also over ssh -X) both come through arboard. On Wayland they come through smithay-clipboard on the app’s own Wayland connection, as egui-winit reads its clipboard; arboard alone would need the data-control protocol, which GNOME lacks. Elsewhere (macOS, Windows), and on a Wayland compositor without the primary-selection protocol, there is no primary selection, and middle-click reads the clipboard.

A read can be slow (X11 asks the owner, which may hang, for up to 4 s per format) so the app never reads on its own thread: a Worker owns the selection on a thread of its own.
