Environment variables

variableused bymeaning
ARCHIVEVIEW_LOGarchiveviewlog level on stderr: error, warn (default), info, debug or trace. Below debug, the egui, eframe, winit and EPICS libraries log warnings only.
ARCHIVEVIEW_UI_SCALEarchiveviewas --ui-scale
XDG_CONFIG_HOMEarchiveviewthe config folder is $XDG_CONFIG_HOME/archiveview when set, else ~/.config/archiveview
EPICS_CA_ADDR_LIST, EPICS_CA_AUTO_ADDR_LIST, EPICS_CA_SERVER_PORT, ...live PVsthe standard Channel Access client settings
EPICS_PVA_ADDR_LIST, EPICS_PVA_AUTO_ADDR_LIST, ...live PVsthe standard PV Access client settings, for pva:// PVs
LIBGL_ALWAYS_SOFTWARE and friendsarchiveview-sshset by the script; see Run over ssh

The archiver URL has no environment variable; use --archiver (which is remembered in settings.json) or the archiver pill.
