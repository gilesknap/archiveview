The synthetic PVs: deterministic functions of time on a fixed sample grid.

PVSignal
MOCK:SINE1 Hz, 10-minute-period sine, EGU mA, PREC 3 (MINOR alarm near the top)
MOCK:RAMP0.1 Hz sawtooth 0..100 over an hour
MOCK:NOISE10 Hz noise on a slow drift, seeded per sample (no RNG state)
MOCK:SLOWone sample every 5 minutes (so optimized returns raw)
MOCK:STEPa value that holds for 4 minutes, then jumps (1 s grid)
MOCK:ENUMinteger 0..3, sampled every minute
MOCK:STRINGtext
MOCK:WAVE8-element array
MOCK:NANsine with a NaN every 50th sample and severity-3 cnxlostepsecs gaps
MOCK:BIG1 Hz sine of amplitude 3e10 (Java 3.0E10 notation on the wire)
bl01t:A, bl01t:B, bl01t:SUM, BL01T-MO-SIMC-01:M1.RBV, BL01T-MO-SIMC-01:M2.RBVnames bobview-testioc serves, so archive and live join up

Every value is a pure function of the sample’s absolute grid index (t / period), so two servers started at different times agree on every sample they both have. “Noise” is a hash of that index.
