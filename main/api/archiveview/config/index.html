Module config 

Source
Expand description

Settings and saved views in $XDG_CONFIG_HOME/archiveview (by default ~/.config/archiveview), the same way bobview keeps ~/.config/bobview:

  • settings.json: Settings.
  • views/<name>.json: a View; views/default.json opens at startup when no PVs or --view are given.

Files are pretty JSON written atomically (hidden temp file, then rename). Only the standalone app uses this module; an embedding app keeps Views in its own config. (Adapted from bobview’s layout.rs.)
