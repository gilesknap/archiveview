Fonts and colours. install_fonts is bobview’s (style.rs); the trace palette is a Tableau-like set in bobview’s order, lightened in dark mode.

Constants§

BOLD
A font family registered by install_fonts; regular is egui’s proportional.

Functions§

adapt
A colour as drawn on a dark background: moved 22% of the way to white so it keeps its contrast.
bold
A bold font of size, when the app installed one; else egui’s default (an embedding host may not have BOLD).
install_fonts
Install Liberation Sans (the font Phoebus and bobview use) ahead of egui’s built-in fonts, which stay as fallbacks for symbols. Only the standalone app calls this: an embedded plot uses its host’s fonts.
live
The “live” accent: the Live pill’s dot (only; the now marker is grey, as red is also a trace and an alarm colour).
palette
The ith palette colour, for a light or dark background.
parse_hex
#rrggbb (or rrggbb) as a colour.
severity
The alarm colours of the Phoebus palette (MINOR, MAJOR, INVALID).
