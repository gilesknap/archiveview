archiveview: archived and live EPICS PV time-series plots.

The reusable part is Plot, an egui widget that bobview (or any egui app) can embed: it owns its traces, archive fetches and live subscriptions, but no window, no eframe::App, no process-global state (bar an id counter, see Plot::with_id_salt), and it borrows the caller’s [pv::PvManager] (and through it the tokio runtime its fetches run on). Several Plots can live side by side, and one works with no archiver at all (live only).

app::ArchiveApp is the standalone application around one Plot: window chrome, saved views, settings and search history in ~/.config/archiveview. main.rs adds only the command line. Both, and snapshot mode, are behind the default app feature: a host embedding Plot turns it off (default-features = false) and depends on egui only, not eframe.

Modules§

app
The standalone application: one Plot filling the window, plus the view menu, settings and theme. Shared by eframe and snapshot mode.
config
Settings and saved views in $XDG_CONFIG_HOME/archiveview (by default ~/.config/archiveview), the same way bobview keeps ~/.config/bobview:
history
Recent searches: the search box’s terms that were useful, newest first.
plot
Plot: the embeddable archived + live time-series widget.
snapshot
--snapshot OUT.png: run the app headless and rasterise one frame in software, so no GPU or display is needed (adapted from bobview’s snapshot.rs). Used by CI and the docs, and to check the UI.
style
Fonts and colours. install_fonts is bobview’s (style.rs); the trace palette is a Tableau-like set in bobview’s order, lightened in dark mode.
view
A view: what a plot shows. Saved as JSON in ~/.config/archiveview/views/<name>.json and returned by crate::Plot::view so an embedding app (bobview) can store it in its own layouts.

ArchiverClient
An Archiver Appliance retrieval service. Cheap to clone; holds no connection state, so it can be shared freely between threads and between several plots.
