archiveview

Command line

archiveview [OPTIONS] [PV ...]
archiveview-mockarchiver [--port PORT] [--bind ADDR]

archiveview --help prints the same list.

archiveview

argumentmeaning
PV ...PVs to plot. A plain name is Channel Access; pva://name is PV Access. With PVs given, archiveview starts a new view of them rather than opening the default view.
-a, --archiver URLthe Archiver Appliance retrieval URL, e.g. http://host:17668. Phoebus's pbraw://host:17668/retrieval works too, as plain HTTP. /retrieval is added unless the URL ends with it. Overrides archiver_url in settings.json; with neither, the plot is live only.
--no-archiveruse no archiver, even if settings.json names one: live values only.
--view NAMEopen the saved view NAME from ~/.config/archiveview/views/. Giving PVs as well is a usage error.
-r, --range SPANthe time span to show, ending now: 1h, 8h, 7d, 90m, 2 days, 1 hour 30 min. Default 1h.
--theme system|light|darkthe colour theme. Default: theme in settings.json, else system (follow the OS).
--ui-scale Fscale the whole interface by F, e.g. 1.25. Default: ARCHIVEVIEW_UI_SCALE, else 1.
--version, --help

Snapshot mode

argumentmeaning
--snapshot OUT.pngrender to a PNG without opening a window, then exit
--size WxHimage size in pixels. Default 1280x800.
--scale-factor Fpixels per point, as on a high-DPI screen. Default 1.
--wait SECONDSrender at least this long before writing, and until archive requests finish (at most 60 s). Default 2.
--hover X,Yrest the pointer at this pixel, to show the crosshair readout
--search TEXTtype TEXT into the search box, to show its matches

Snapshots use the light theme unless --theme dark is given. See Take snapshots.

Startup

  1. PVs on the command line start a new view of those PVs, over --range.
  2. Otherwise --view NAME opens that view.
  3. Otherwise the saved default view opens, if there is one.
  4. Otherwise the plot starts empty, ready for a PV name.

Exit status

0 on success, 2 for a usage error (an unknown option or a bad value), 1 for any other failure, such as a snapshot that can't be written. A --view that can't be read, or a bad archiver URL, is a usage error. Messages are printed as archiveview: message.

archiveview-mockarchiver

argumentmeaning
--port PORTthe port to serve on. Default 17668.
--bind ADDRthe address to listen on. Default 127.0.0.1; use 0.0.0.0 to serve other machines.

It runs until killed. See Mock archiver.
