archiveview::plot

Struct Plot 

Source 
pub struct Plot { /* private fields */ }
Expand description

An archived + live plot of a set of PVs on one shared time axis.

Owns its traces, background fetches and live subscriptions; dropping it unsubscribes and abandons in-flight fetches. Its only shared state is the counter Plot::new salts ids with, so any number may exist at once.

Array (waveform) PVs are not plotted: their chip shows the latest array ([936] 0, 0, 0, …) and says “not plotted”, and their history is not fetched. (Earlier builds plotted element 0 over time; a host such as bobview that wants a waveform’s elements should show them itself.)

Show the ↶ ↷ buttons and take Ctrl+Z, Ctrl+Shift+Z, Ctrl+Y and the mouse’s back and forward buttons (on by default). A host with its own undo turns them off; the plot still records its steps, for Plot::undo and Plot::redo.

pub fn set_undo_enabled(&mut self, on: bool)

Record undo steps (on by default). Off, the lists are cleared and nothing is recorded, nor kept for it (removed traces are dropped at once), and the controls do nothing: for a host with an undo of its own that has no use for the plot’s. On again, recording starts from the state then.

Let the user switch archivers in the archiver pill, and have Plot::set_view switch to a view’s archiver.
