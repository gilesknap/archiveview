Crate archiver 

Source
Expand description

A client for the EPICS Archiver Appliance retrieval API.

The pieces are split so that a browser build could reuse everything but the HTTP: ArchiverClient builds the request URLs (*_url), the parse_* functions decode the bodies, and the blocking get_data/search/metadata methods do both over ureq on native targets. In a browser those methods fail at once.

Times are UTC seconds since the Unix epoch as f64 (sub-microsecond resolution for current dates), the same as bobview’s trend and archiveview’s plot.

See DESIGN.md at the repository root for the wire format and its surprises (bare NaN tokens, string PREC, [ ] for no data, binned [mean, std, min, max, count] values from optimized_N).

format_time
t (UTC epoch seconds) as YYYY-MM-DDTHH:MM:SS.mmmZ, rounded to the millisecond. Non-finite or out-of-range times are clamped to the epoch and to year 9999.
parse_data
Decode a getData.json body: one TimeSeries per PV, empty for [ ]. Tolerates bare NaN/Infinity/-Infinity, string or numeric PREC/LOPR/HOPR, unknown keys, and fields objects. A severity-3 sample whose fields hold cnxlostepsecs becomes a Sample::gap. A 5-element array val on a scalar PV is an optimized bin (binned = true); other arrays are waveforms (val holds element 0).
